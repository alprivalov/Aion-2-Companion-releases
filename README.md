# Daevas

Companion app for Aion 2 (Windows): market prices and crafts, DPS meter, daily and weekly routine, map, deliveries. Site: https://daevas.gg · Discord: https://discord.gg/BarbDTh6k5

## Install

Download `Daevas-win-Setup.exe` from the [latest release](https://github.com/alprivalov/Aion-2-Companion-releases/releases/latest) and run it. Updates install from inside the app.

- **Windows 10 (1809) or 11.** About 150 MB, .NET included.
- **SmartScreen**: the app is not signed yet, so Windows may say "Windows protected your PC". Click *More info*, then *Run anyway*.
- **Npcap**: reading the game (DPS, routine, deliveries) needs Npcap. The app offers to install it on first launch.
- **Live market prices** is an option, off by default. It reads the market with your game session, which the game's terms forbid: use it at your own risk.

## Uninstall

Windows Settings › Apps › Daevas › Uninstall.

## Report a bug

In the app: Settings › About › Report a bug. It gives you a short code: quote it on the Discord or in an [issue](https://github.com/alprivalov/Aion-2-Companion-releases/issues).
